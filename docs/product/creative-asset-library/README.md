# 创作资产库

状态：`目标产品需求，尚未实现`。

更新时间：2026-08-05。

上位规范：[ContentCloud 平台基线](../../foundation/README.md)。客户任务体验参见[客户创作台](../customer-creation-studio/README.md)，对外表达遵循[产品叙事规范](../00-product-narrative.md)。

## 1. 产品结论

ContentCloud 已经拥有来源、受权利约束的参考素材、批准快照、生产文件、交付包和追溯关系，但客户还缺少一个统一、简单、可跨任务复用的入口。

创作资产库解决的不是“把文件放进一个网盘”，而是让客户能够回答三个问题：

1. 我们已经积累了什么？
2. 哪些内容现在可以安全复用？
3. 怎样把它直接带入下一次创作？

核心叙事是：

> 每完成一次创作，都在积累下一次可以直接使用的品牌资产。

在统一客户叙事中，资产库同时位于起点和终点：

```text
已有资产 -> Content Work OS 创作任务 -> 已批准结果 -> 资产库 -> 下一次创作
```

## 2. 产品边界

创作资产库是客户侧产品入口，不是新的业务事实拥有者。

```text
Source / Asset / Knowledge / ApprovedSnapshot / Artifact / DeliveryPackage
                                  |
                                  v
                    CreativeAssetCatalogProjection
                                  |
                     +------------+------------+
                     |                         |
                     v                         v
              客户创作资产库              运营资产治理
              浏览、搜索、复用            权利、失效、追溯
```

- 现有 `Asset` 保持“受权利约束的参考素材”语义。
- `CreativeAssetCatalogItem` 是可重建的只读目录项，只引用事实对象，不复制正文。
- 新任务通过固定版本和摘要引用资产，不复制一份脱离来源的新正文。
- 权利到期、来源失效和版本替代会改变“是否可用于新任务”，但不会删除历史交付和审计。

## 4. 第一阶段结果

第一阶段只建立完整复用闭环：

```text
保存或批准内容
  -> 自动进入统一目录
  -> 客户搜索、筛选和预览
  -> 查看来源、版本、权利和可复用状态
  -> 引用到新任务
  -> 新结果继续沉淀
```

第一阶段不建设通用数字资产管理系统、三维画布、任意关系图、全盘文件扫描或低代码资产编排器。

## 5. 固定原则

1. 客户看到创作语义，运营看到治理语义，二者读取同一目录投影。
2. 目录项不是权威正文，投影损坏后可以从事实对象重建。
3. 不是所有搜索结果都进入全局资产库；只有保存、选择、批准或交付的内容才沉淀。
4. 正式复用必须固定底层对象版本和摘要，不能引用“当前最新”。
5. 失效和权利变化默认阻止新任务继续使用，并能定位受影响下游。
6. 客户不能通过资产库绕过来源、权利、事实、审批和交付门禁。
