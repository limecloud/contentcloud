# Content Work OS 与 Claude Code

状态：**底层工作区可用，网页完整入口有限支持**。

Content Work OS 已支持 Claude Code 的电脑端资料整理、项目文件夹登记、标准插件投影，以及由控制面生成的受项目/修订摘要约束的命令交接。`bootstrap preflight/plan/apply/resume --host claude` 会按 Claude Code 自身版本和 `claude-plugin` 工作区目标执行准入；完整的网页客户入口、跨页面继续工作体验和真实创作流程仍在验收中。

## 当前能力

| 能力 | 状态 |
| --- | --- |
| 电脑上的资料整理和修改 | 可用 |
| 连接项目文件夹 | 可用 |
| Claude 插件和中文工具 | 部分可用 |
| 自动启动连接服务 | 部分可用 |
| 自动识别当前项目文件夹 | 已实现 |
| 准备项目文件夹（CLI `--host claude`） | 可用 |
| 控制面生成项目/修订命令交接 | 可用 |
| 网页和电脑之间的完整继续工作体验 | 即将支持 |
| 创作所需工具 | 即将支持 |
| 页面内工作台 | 尚未验证 |

当前的电脑端自动化由平台在受控的临时目录中调用 Claude Code，并要求返回平台可以读取的结果。它还不是一条可以直接给客户使用的完整创作流程。

## 当前限制

- 网页工作台的“连接工作电脑”尚未完成 Claude 宿主选择、启动和浏览器回连的完整验收；不要把 CLI bootstrap 的可用性当成网页入口已经发布。
- 控制面已经可以为 Claude Code 生成受约束的 `claude <prompt>` 命令；网页工作台内的完整入口和复制/启动交互仍未验收。
- 当前没有“Claude Code × 营销视频”的完整场景教程。
- Claude Code 使用自己的插件和配置方式；不要套用 Codex 的插件、快捷链接或继续工作命令。
- Claude Code 的浏览器集成可以操作本地页面，但不会自动接收 Content Work OS 的继续工作信息，也不能替你确认安全信息。
- Claude Code 当前不能保证显示完整的内嵌工作台；在完整页面不可用时，会退回文字和按钮操作。

在这些能力正式发布前，请使用 [Codex](codex.md) 完成完整的网页与电脑协作流程。页面能力状态会直接来自连接工具状态表；能力开放后无需更换文档入口。
