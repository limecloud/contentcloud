# Content Work OS 使用文档

Content Work OS 是一个帮助团队完成内容创作、确认和交付的工作台。你可以在网页中选择任务、提交资料、查看进度、确认结果并下载交付文件；需要整理资料或继续修改时，再连接支持的连接工具。

这份文档主要给内容团队使用，也保留了连接工具需要的少量命令名称：

- 在 Content Work OS 的 `/docs` 文档中心按连接工具或内容形式查找指南。
- 连接工具和开发人员可以直接读取同一份 Markdown 文档。

文档只描述已经验证的能力。标记为“有限支持”或“即将支持”的页面不会提供尚未实现的安装、初始化、交接或发布命令。

## 从哪里开始

1. 阅读[开始使用](getting-started.md)，了解如何从网页工作台开始任务，以及何时连接工具。
2. 阅读[内容审核与交付流程](concepts/governed-workflow.md)，了解草稿、审核通过版本和交付文件的区别。
3. 按连接工具查看接入状态，或按内容形式查看当前支持范围。
4. 只有找到明确标记为“可用”的场景指南后，才执行对应流程。

## 状态说明

- **可用**：已有受支持的产品流程和可验证实现。
- **有限支持**：部分功能可用，但还不能完成完整连接或生产流程。
- **即将支持**：已经在准备，但目前还不能实际使用。

其他产品的兼容目录只作为参考，不会直接改变这里的可用状态。每种连接工具都必须独立完成安装、项目文件夹连接、权限和安全检查。

遇到任务、连接工具、项目文件夹或继续工作问题时，查看[故障排查](troubleshooting/workspace-and-handoff.md)。

如果你负责平台管理或开发，可以在内部设计文档中查看产品分工和系统结构；本目录只描述已经验证、可以照着使用的客户功能。
