# 使用 Codex 制作营销视频内容

状态：**可用**。

本教程适用于已经登录 Content Work OS、拥有项目权限，并能在电脑上运行 Codex 的用户。

## 1. 连接工作电脑

1. 在 Web 工作台创建或选择项目。
2. 打开“连接工作电脑”。
3. 创建连接会话并复制页面生成的连接文字。
4. 在有本机权限的 Codex 会话中按页面提示完成连接。
5. 核对将要改动的目录和版本，确认后再应用。
6. 等待网页工作台显示项目文件夹已连接。

安装方式和连接命令以 [`/codex`](/codex) 为准。不要替换页面给出的来源、版本或插件名称。

## 2. 在新对话恢复项目

安装或环境变更后，在已验证的项目文件夹中新建 Codex 对话。先调用：

```text
workspace_context
```

如果结果是 `repair_required`，再调用 `workspace_doctor`。如果存在多个工作记录，先选择准确的一条；如果存在“可继续（`ready`）”的继续工作记录，接受后重新核对记录。

## 3. 准备可信输入

1. 导入项目资料并确定本次要使用的范围。
2. 整理出带原文依据的参考内容。
3. 检查后提交内容版本。
4. 在网页工作台完成人工审核，下载准确的已确认版本。

模型常识、历史聊天和未经确认的客户材料不能替代可核对的参考内容。

## 4. 形成策略与创作简报

1. 选择明确受众、渠道、场景和营销目标。
2. 形成一份受众和营销方向草稿。
3. 创建引用已确认资料的创作简报。
4. 写清楚可使用的主张、禁用表达、行动引导、实验变量和内容数量。
5. 运行检查；缺少资料时保留“暂时不能继续（`blocked`）”状态并列出原因。

## 5. 生成并审核营销内容

1. 为当前任务创建或选择工作记录。
2. 确认只有你在编辑，并固定创作简报与已确认资料。
3. 生成营销视频剧本草稿。
4. 检查引用、主张、素材权利、时长、画幅和完整性。
5. 执行 `publish_preflight`，查看本次提交的范围、记录和影响。
6. 确认同一修改范围后再提交，创建不会被悄悄改动的版本。
7. 在网页工作台审核；确认后生成已确认版本，退回后会保留修改意见。

## 6. 处理退回意见

在网页工作台点击“在连接工具中修改”，选择 Codex。系统只会打开带预填连接文字的新对话，不会自动发送，也不会自动选择项目文件夹。

新对话重新调用 `workspace_context`，读取目标版本、记录和审核意见。修改时保留来源版本、已解决意见和变更说明，再提交新版本。

## 7. 生成分镜与交付

1. 下载明确的已确认版本。
2. 根据已确认内容生成分镜；不要直接使用未确认草稿。
3. 通过分镜检查后生成视频制作文件。
4. 核对素材、使用权限、镜头连续性、提示词和文件记录。
5. 分别记录“制作文件已生成”和“外部平台已发布”。

## 8. 使用 Seedance 2.5 制作视频

如果平台管理员已经配置并开启 Seedance 2.5，网页工作台会在符合条件的任务中显示视频制作入口。你只需要：

1. 确认当前分镜已经审核通过。
2. 选择制作方式、画幅和时长，并查看预计费用。
3. 等待平台完成提交、制作和下载；服务商状态不明确时不要重复创建任务。
4. 等待视频通过技术和内容检查，再把它作为候选成片确认或继续修改。

当前只支持单镜头的文生视频和图生视频。多镜头、续写、编辑、音频驱动和超长视频仍需使用手动方式，或等待页面显示可用。

服务商账号、费用上限和安全密钥由平台管理员维护，普通用户不需要填写 API 密钥或修改服务器设置。

遇到连接或继续工作问题时，查看[项目文件夹连接与继续工作故障排查](../../troubleshooting/workspace-and-handoff.md)。
