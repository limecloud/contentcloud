# 使用 Codex 制作微信公众号文章

状态：**可用，需要管理员为客户开启**。

本教程适用于已经连接 Content Work OS 项目文件夹、拥有项目权限，并已由平台管理员开启微信公众号文章的客户。

## 1. 开通并刷新环境

1. 平台管理员在“系统后台 / 客户 / 内容能力”开启“公众号文章”。
2. 在项目的连接入口刷新可用功能列表。
3. 确认公众号文章工具已安装；安装或变更后新建 Codex 对话。
4. 在项目文件夹中调用 `workspace_context`，确认可用内容包含 `wechat_article`。

不要编辑可用功能列表或本地配置来模拟开通。连接工具和平台都会重新验证客户权限。

## 2. 准备已确认的参考内容

1. 选择或创建工作记录（`LocalRun`），并取得编辑许可（`claim`）。
2. 从已确认的原文依据中整理事实、营销主张、素材和使用权限。
3. 运行检查，提交内容版本并在网页工作台完成审核。
4. 下载已确认的参考内容。

未经确认的资料可以帮助发现缺口，但不能作为正式事实或商业主张依据。

## 3. 创建文章创作简报

1. 使用 `$contentcloud-article-planning` 定义主题、读者收益、结构、语气、行动引导和唯一实验变量。
2. 把必需事实与已确认商业主张分别写入文章简报。
3. 缺少事实、营销主张、素材或使用权限时保持“暂时不能继续（`blocked`）”，列出原因和缺少的内容。
4. 调用 `article_brief_lint`。
5. 通过 `publish_preflight` 展示精确计划，用户确认同一 `plan_id` 后再 `publish_apply`。
6. 在网页工作台确认文章简报，并下载文章简报的已确认版本。

## 4. 生成和修订文章

1. 使用 `$contentcloud-longform-writing` 调用 `article_batch_create`，固定已确认的文章简报和参考内容。
2. 在返回的目录中生成文章正文，使用标题、正文、列表和图片等内容块。
3. 为事实、商业主张和引语标明已确认的原文依据；观点、个人经历和假设必须清晰分类。
4. 需要配图时使用 `$contentcloud-article-visuals`，只使用已经确认有使用权限的素材。
5. 依次调用 `article_item_lint`、`article_batch_lint` 和 `article_batch_finalize` 完成检查与定稿。
6. 通过提交前检查与确认，提交文章版本（`content_batch`）。

网页工作台退回后，从原内容版本创建新的文章草稿，填写来源版本、已解决意见和变更说明。调用 `article_item_diff`，只修改用户确认过的内容位置。

## 5. 审核与批准

公共审核页会安全展示文章标题、摘要、作者、正文、事实说明和引用，不会执行文章中的网页代码。审核人可以确认或退回；确认后平台会创建不会被悄悄改动的已确认版本。

电脑里的草稿、已提交版本和已确认版本是三种不同状态。文件中出现“已确认”文字不能替代网页审核。

## 6. 生成本地交付包

1. 下载包含目标文章的已确认版本。
2. 使用 `$contentcloud-wechat-delivery` 调用 `wechat_package_export`。
3. 对返回的 `providers/wechat-official-account/package.json` 调用 `wechat_package_lint`。
4. 检查本地预览、素材映射、文件摘要和操作说明。
5. 由操作人员登录公众号后台，上传素材、粘贴内容、预览并发布。

技能不会登录、创建公众号草稿、上传素材或发布文章。外部发布完成后，另行登记外部绑定和结果，不要把本地交付包状态当作平台发布状态。
