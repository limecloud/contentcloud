# 营销视频

状态：**可用**。

营销视频是 Content Work OS 当前正式支持的内容形式。系统会依次帮助你整理资料、确定受众、写剧本、做分镜、准备视频制作文件、审核和交付。

## 制作流程

```text
来源资料
  -> 可核对的参考内容
  -> 受众与营销方向
  -> 创作简报
  -> 营销视频剧本
  -> 网页工作台审核与已确认版本
  -> 分镜与视频制作文件
```

## 当前可用步骤

- 项目管理：读取、恢复、继续工作和提交内容。
- 资料整理：从已确认的参考资料中整理可用内容。
- 营销视频剧本：生成或修改带来源说明的营销内容。
- 抖音受众策略：形成抖音电商受众策略。
- 分镜制作：从已确认内容生成分镜方案。
- 视频制作文件：生成给视频工具使用的制作文件。
- Seedance 2.5 平台制作（预览）：需要管理员配置服务并通过费用确认，正式开放前仍在验收。

## 使用前检查

- 只使用当前已确认内容中的可用事实、营销主张、素材和权利记录。
- 缺少正式输入时可以形成已阻断候选，但不得伪造依据。
- 分镜和 Seedance 只能使用通过检查的上游内容。
- Seedance 2.5 视频制作需要从平台显示的视频制作入口开始；手动上传或平台生成的视频，都要再次通过视频质量和内容检查。
- 本地草稿、提交版本、已确认版本和外部发布状态必须分别显示。
