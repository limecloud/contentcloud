# 微信公众号文章

状态：**可用，需要管理员为客户开启**。

Content Work OS 支持根据已确认资料和文章简报生成结构清晰的文章，在网页工作台中审核准确版本，并导出微信公众号本地交付文件。平台管理员必须先为目标客户开启“微信公众号文章”；视频剧本仍是所有客户默认可用的内容形式。

## 当前范围

- 文章简报会记录选题、读者收益、结构、语气、行动引导、资料和主张要求。
- 文章正文按标题、摘要、正文、列表、引语、图片和提示等内容块保存，便于审核和导出。
- 事实、商业主张和引语都会标明对应的已确认资料或原文依据。
- 公共审核页会按文章格式显示正文、主张和引用，审核人可以直接确认或退回。
- 已确认版本可以导出为网页、Markdown、素材清单、操作说明和本地预览。

## 开通与环境

1. 平台管理员在系统后台为客户开启“微信公众号文章”。
2. 连接工具操作者通过页面提供的恢复流程刷新可用功能列表。
3. 在同一个项目文件夹中新建 Codex 对话并调用 `workspace_context`。
4. 确认返回的可用内容包含 `wechat_article`，再开始制作文章。

连接工具只能读取平台给出的可用功能，不能自行开通。客户关闭能力后，平台会在创建、审核和最终确认时拒绝公众号文章。

## 交付边界

首版只生成本地交付包。以下动作必须由操作人员在微信公众号后台完成：

- 登录账号。
- 上传或替换素材。
- 检查预览和移动端排版。
- 创建草稿或正式发布。
- 把外部内容 ID、URL 和发布时间登记回 Content Work OS。

Content Work OS 不索取公众号登录信息；“交付文件已生成”也不等于“公众号已发布”。

完整流程见[使用 Codex 制作微信公众号文章](../guides/wechat-article/codex.md)。
