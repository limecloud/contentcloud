# 06：执行面、安全与治理

> 阅读对象：安全、平台和执行适配模块负责人。本文件规定智能体能访问什么、哪些操作必须由服务端或人工决定。

## 1. 安全边界声明

V8 不再使用含糊的“零执行”说法。准确的安全边界是：

> ContentCloud 服务端不执行客户上传的任意代码，也不在同步 HTTP 请求中运行通用大模型。受信任的本地守护进程（Daemon）或白名单工作进程（Worker），只能根据已签名的 `ExecutionBundle`，在最小权限、预算限制和全程审计下调用明确声明的执行能力（`Capability`）。

这不等于操作系统级安全沙箱。当前 Automation 工作目录的 `0700` 权限、只读契约和进程组取消机制可以降低误操作风险，但无法阻止拥有较高本机权限的智能体读取当前用户可访问的其他文件。因此，V8 在动态创建智能体之前，必须把隔离等级作为明确的调度条件进行校验。

## 2. 信任边界

```text
不可信输入
源文件 / 网页 / 服务商响应 / 智能体生成文本
                         │
                         ▼
┌───────────────────────────────────────────────────────────────┐
│ ContentCloud 校验边界                                         │
│ 数据结构 · 租户/项目归属 · 摘要 · 策略 · 人工审批节点         │
│ 行级安全 · 并发版本控制 · 幂等 · 权利 · 费用 · 数据出口       │
└───────────────────┬───────────────────────────┬───────────────┘
                    │                           │
                    ▼                           ▼
             可信控制数据                    候选数据
      执行实例/租约/策略/审计            智能体输出/产物
                    │                           |
                    └────── 审核 / 人工审批节点 ──────┘
```

智能体的输出一律先作为候选数据。只有通过服务端校验，且所需的人工审批节点均已通过后，候选数据才能成为正式内容数据或交付输入。智能体不能靠输出一段文字来修改策略、工具白名单、预算或身份。

## 3. 执行面类型

执行面（Execution Plane）分为以下类型：

| 类型 | 运行内容 | 信任边界与限制 |
| --- | --- | --- |
| `trusted_local_agent` | 用户本机的 Codex、Claude 等智能体 | 必须由用户明确启用；需要提示本地资料可能被读取；不得宣称为安全沙箱 |
| `restricted_agent` | 隔离环境中获准使用的智能体执行适配器 | 限制工作目录、网络和工具白名单；使用短期凭据；适配器必须通过一致性测试 |
| `deterministic_worker` | 解析、校验、渲染、生成投影和归档 | 只运行正式发布的二进制文件，只能调用白名单内的 `Capability` |
| `provider_worker` | 向外部媒体服务商提交任务、查询进度和下载结果 | 只允许访问批准的域名、执行配置和 `SecretRef`；所有外部写操作必须登记到外部操作台账 |
| `human_gate` | 人工批准、驳回、补充材料和异常对账 | 不占用执行器；必须审计操作人身份和决定理由 |

首版不允许运营人员上传脚本并直接注册为执行器能力。新增 `Capability` 必须经过代码评审、签名发布和部署流程，才能进入白名单。

## 4. 按执行尝试隔离的运行时网关

本地守护进程为每次执行尝试（`Attempt`）创建独立的运行时网关会话：

```text
控制面发放租约
  -> 服务端只保存不透明运行令牌的哈希
  -> 本地守护进程取得短期凭据
  -> 本地网关绑定执行尝试（`Attempt`）、执行实例（`JobRun`）和执行步骤（`NodeRun`）范围
  -> 智能体只取得网关通信入口和 ContextView
  -> 每次调用都重新校验有效租约和策略
```

约束：

- 智能体不能取得设备令牌、数据库 DSN、租户 API 令牌或服务商密钥。
- 网关凭据不能跨执行步骤、执行尝试、执行实例或设备复用。
- 租约过期、任务取消或权限撤回后，所有写工具必须立即默认拒绝执行。
- 本地通信优先使用标准输入输出或 Unix Socket；使用远程 HTTP 时，必须采用限定接收方的短期令牌和 TLS。
- 工具返回有大小、分页和字段脱敏限制。
- 网关只接受命令调用，不向智能体暴露数据库行锁或事务句柄。

## 5. 宿主权限

### 5.1 当前风险

当前 `internal/agentadapter/adapter.go` 中：

- Codex 使用 `--dangerously-bypass-approvals-and-sandbox --ephemeral`。
- Claude 使用 `--permission-mode bypassPermissions --no-session-persistence`。

这种配置只适用于用户明确授权的本地单次执行，不适合作为动态多智能体运行时的默认配置。Runtime 不能直接在该配置上开放子智能体创建能力。

### 5.2 隔离配置（`IsolationProfile`）

每个智能体节点必须声明一种已经发布的隔离配置：

| 配置 | 适用场景 | 最低控制要求 |
| --- | --- | --- |
| `trusted_local_single_run` | 用户本人机器、单节点 | 用户主动选择、私有工作目录、不得创建子节点、严格校验输出结构 |
| `workspace_restricted` | 本地 V8 智能体 | 只允许写指定工作目录；限制命令和工具白名单；按域名限制网络；控制操作只能经过网关 |
| `container_restricted` | 受信任的服务端智能体 | 非 root 用户、只读镜像、临时卷、网络白名单、资源限额、通过边车解析 `SecretRef` |
| `deterministic_only` | 高风险租户或高风险数据 | 不启动通用智能体，只运行批准的确定性执行器 |

如果宿主无法满足节点所要求的隔离配置，节点进入 `waiting(resource)` 状态；系统不能自动降级为 `trusted_local_single_run`。

## 6. 权限继承

子节点或子智能体的有效权限取以下策略的交集：

```text
租户策略
  ∩ 项目策略
  ∩ 执行实例的 RuntimePolicy
  ∩ 父智能体策略
  ∩ `NodeSpec` / `ExecutionProfile`
  ∩ 当前人工审批结果
```

任何一层拒绝，该操作就必须被拒绝。主控智能体可以缩小子智能体的上下文、工具权限和预算，但不能扩大以下范围：

- 可读取的正式业务对象和共享状态集合（`StateCollection`）。
- 可写入的状态集合和操作类型。
- 可使用的模型、工具、MCP 服务、外部服务商、区域和网络出口。
- 最大并发数、层级深度、后代节点数、Token、费用和总运行时长。
- 可执行的外部操作类型，以及是否需要人工授权。

## 7. 提示词注入与数据污染

### 7.1 数据/指令分离

每项上下文都必须标明来源类别；以下名称是固定的来源枚举：

```text
trusted_policy       服务端规则和签名契约
canonical_fact       已验证并可追溯的业务事实
agent_generated      尚未批准的智能体输出
untrusted_external   网页、上传文件、服务商文本和用户引用内容
```

运行时指令必须明确说明，后两类内容不能改变系统规则。更重要的是，服务端不得从这些字段中解析权限、工具名称、URL、数据结构或预算。

### 7.2 输出验证

- 每个节点的输出必须先通过 JSON 和领域数据结构校验，同时检查大小和对象引用。
- 对象引用必须重新校验租户和项目归属、版本、摘要、状态及使用权利。
- URL 只能指向预先登记的服务商，或者使用经过服务端请求伪造（SSRF）防护的下载句柄。
- 智能体摘要不能自动成为 `Evidence` 或 `ApprovedSnapshot`。
- 输入内容中即使出现“批准”“忽略规则”“使用另一个账号”等文字，也不能产生任何控制效果。

### 7.3 工具说明

运行时网关的工具说明随版本固定发布，不拼接任何来源文本。工具参数采用结构化枚举、ID 和摘要，不能由自由文本决定高风险操作目标。

## 8. 外部操作治理

以下操作在执行前必须创建外部操作记录（`SideEffectRecord`）：

- 向付费模型或媒体服务商提交任务。
- 外部上传、发布、发送、删除、下架或账号操作。
- 触发第三方工作流、付款或消耗不可退额度。
- 对外可见的签名交付链接创建。

授权检查包括：

- 外部操作类型是否在节点和隔离配置的白名单中。
- 操作目标是否属于已经批准的租户绑定。
- 数据披露清单、处理区域和保留政策是否符合要求。
- 是否提供稳定的幂等键和请求摘要。
- 是否已经预留预算。
- 所需的人工审批节点是否已经通过。

如果外部系统返回结果不明确，必须先对账，不能直接重试。补偿操作必须记录原外部操作 ID，不能通过删除审计记录来伪装操作“没有发生”。

## 9. 人工审批节点

下列事项不能由执行当前节点的智能体自行批准：

- 证据、产品事实和商业主张。
- 素材使用权、肖像权、音乐和第三方授权。
- 超过阈值的模型或外部服务商费用。
- 剧本、分镜、拍摄版本和最终成片。
- 首次连接新的外部账号、服务商或数据出口。
- 无法自动对账、状态为 `unknown` 的外部操作。
- 创建分支执行时已经过期或适用范围发生变化的批准。

人工审批节点（`Human Gate`）必须记录输入对象版本、审批决定、理由、操作人、时间、过期时间和适用分支。上游对象发生变化后，原审批结果不能继续用于批准新的内容摘要。

## 10. 密钥与认证

- 外部服务商密钥只能存放在部署环境或密钥管理系统中，并通过 `SecretRef` 解析；不得进入业务表、`JobEvent`、共享状态、提示词或前端。
- 本地智能体的登录状态由本地宿主管理。ContentCloud 不上传 Cookie、消费端令牌或凭据文件。
- 平台托管的 Claude Agent SDK 必须使用供应商许可的 API 认证方式，不能复用或转售消费套餐的登录状态。
- Codex SDK/App Server 面向第三方租户的认证和分发必须单独完成供应商条款评审。
- 所有回调都必须验证签名、时间窗、随机数、服务商配置和重复事件。
- 短期下载 URL 只能在授权请求发生时生成，不持久化到事件或完整执行记录（`Transcript`）。

## 11. 租户隔离与审计

V8 新表必须具备与现有规范表一致的行级安全策略（RLS）：

- 租户过滤条件必须覆盖 `JobRun`、计划、节点、智能体、共享状态、检查点、外部操作、事件和资源预留。
- 服务层必须再次校验项目范围。
- 唯一键必须包含租户和执行实例范围，避免跨租户的幂等冲突泄露信息。
- 执行器使用专用角色，只能通过领取、上报和对账 API 操作租约对象。
- 运行诊断查询使用与业务页面相同的操作人和项目权限，不能以“诊断”为由绕过内容权限。

审计正文只保存脱敏摘要和内容摘要。完整外部响应或完整执行记录必须作为受限产物单独存储、单独授权。

## 12. 威胁与控制

| 威胁 | 结果 | 控制 |
| --- | --- | --- |
| 来源文件诱导智能体提高权限 | 越权调用工具或读取数据 | 区分数据和指令；服务端策略不读取内容字段 |
| 子智能体权限膨胀 | 读取同级节点或项目机密 | 父子策略取交集；令牌只对当前执行尝试有效 |
| 无限创建子节点 | Token 或费用失控 | 限制最大深度、节点数、并行拆分数和后代数，并预留预算 |
| 多个智能体互相覆盖状态 | 数据丢失 | 使用比较并交换（CAS）、单写入者、只追加或指定汇总写入者 |
| 向服务商提交请求超时后盲目重试 | 重复扣费 | 将外部操作标记为 `unknown`，完成对账后再决定后续动作 |
| 恶意下载 URL | SSRF 或内网访问 | 服务商域名白名单、DNS/IP 校验、独立下载执行器 |
| 视频或上下文过大 | 内存耗尽或拒绝服务 | 流式处理、大小上限、`ArtifactRef` 和分页 |
| 过期租约迟到上报 | 覆盖新的执行尝试 | 校验 Attempt、owner、fence token、版本和幂等键 |
| 完整执行记录泄露 | 客户数据外泄 | 默认只显示摘要；完整记录作为受限产物保存，并执行保留策略 |
| 分支执行继承过期审批 | 错误交付 | 重新校验权利、人工审批结果、隔离配置、服务报价和预算 |
| 操作人员误点高风险恢复动作 | 重复触发外部操作 | 根据外部操作状态返回当前可执行操作，并要求二次确认 |

## 13. 安全发布门槛

- `trusted_local_single_run` 不得创建动态子节点。
- 运行时网关必须通过跨租户、过期令牌、参数污染和重放测试。
- Codex 和 Claude 适配器必须分别通过权限与沙箱一致性测试；适配器或宿主版本变化后需要重新验证。
- 共享状态、事件、外部操作和完整执行记录相关日志必须通过密钥扫描。
- 服务商文件下载必须通过 SSRF、内容类型、文件特征、大小、时长和内容摘要校验。
- 取消、超时或终止整个进程树后，不得残留仍有高权限的智能体进程。
- 红队测试用例必须证明：来源内容中的提示词注入无法创建未授权子节点、MCP 服务、外部服务商调用或审批决定。
- 正式接入任何宿主或外部服务商之前，必须完成服务条款、数据处理区域和数据保留政策评审。
