# Platform Surface

平台层只放无业务所有权的客户公共能力：会话、租户、权限、错误边界、通知、焦点、可访问性、契约校验和通用网络边界。

这里不能放视频、文章或电商的业务文案、阶段状态、画布组件和对象类型。业务 UI 应放在 `../workbenches/`，无业务所有权的视觉原语继续放在现有共享组件和样式边界中。

## 目录边界

```text
platform/
├── auth/             会话与登录态
├── tenant/           租户、项目和权限上下文
├── contracts/        平台 action、状态和引用的运行时校验
├── errors/           客户可见错误与支持编号
├── accessibility/   焦点、键盘和减少动效策略
└── network/          BFF 请求、重试和分页基础设施
```

这些子目录是目标所有权边界，按需创建，不为尚未存在的功能预建空壳。平台模块只能依赖 `shared` 的无业务 UI 原语和生成的契约；不能导入 `workbenches/<business>`、`admin` 或 Runtime/Provider 内部 DTO。

平台层提供的是受保护的宿主能力，不是统一的客户页面。业务工作台可以选择侧栏、目录、时间线或画布内导航，只要遵守会话、权限、状态、错误和可访问性契约。
